# R90 Claude Code plugins

The `r90` marketplace for Claude Code. It holds the Habitat plugin, which
connects Claude Code to Habitat (sign-in required) and adds its skills.

Install it with one command, which also signs you in to Habitat:

    curl -fsSL https://apollo.adminifi.com/install | bash

On Windows: `irm https://apollo.adminifi.com/install/ps1 | iex`.

This repository is published automatically from Habitat; changes made here are
overwritten.
